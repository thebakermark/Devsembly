# Development VM

Target platform: Ubuntu 24.04 LTS.

Planned services:

- Browser-based VS Code
- OpenClaw
- Archon
- Claude Code
- OpenAI Codex
- Git and GitHub CLI
- Docker Engine and Compose
- Git worktree manager
- PostgreSQL, Redis and MinIO development services
- Playwright and Testcontainers
- Security scanners

The workstation must be operable from a standard browser because the local client may not permit administrator access or software installation.
