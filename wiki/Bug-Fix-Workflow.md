# Bug-fix workflow

1. Create or confirm a reproducible issue.
2. Capture expected and actual behavior.
3. Identify the root cause.
4. Add a failing regression test.
5. Implement the smallest safe fix.
6. Run targeted and full test suites.
7. Run security and documentation checks.
8. Have a different agent review the change.
9. Open a draft pull request.
10. Validate in preview or staging.
11. Merge only after required checks pass.
