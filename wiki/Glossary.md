# Glossary

**Agent:** An AI-driven worker with a defined role, tools, permissions, and task boundary.

**Orchestrator:** The coordinator that routes requests, starts workflows, tracks status, and requests approvals.

**Worktree:** An isolated Git working directory allowing multiple agents to work without overwriting one another.

**Workflow:** A defined sequence of tasks, gates, retries, and outputs.

**Preview environment:** A temporary running deployment for a pull request.

**Staging:** A production-like environment used for final testing.

**Quality gate:** An automated or human-required condition that must pass before work advances.

**Source of truth:** The authoritative record. For Devsembly, GitHub stores code, issues, reviews, and release history.
