# Run your first project

## Example request

Tell the orchestrator:

> Create a new internal web application with authentication, PostgreSQL, automated tests, documentation, a preview deployment, and a staging environment.

## Expected automated sequence

1. Create a GitHub project issue.
2. Product agent defines users, outcome, and acceptance criteria.
3. Architecture agents create the initial design and threat model.
4. Engineering director creates implementation issues.
5. Specialist agents work in isolated branches and worktrees.
6. Quality agents add unit, integration, and browser tests.
7. Security scanners and security agents review the changes.
8. Documentation agent creates setup and operations instructions.
9. Draft pull requests are opened.
10. GitHub Actions validates the work.
11. Coolify creates a preview environment.
12. Human approval allows merge and staging deployment.
