# Monitoring and alerts

Monitor:

- application and API health
- deployment success
- error rate
- response time
- CPU, memory, disk, and container status
- background queues
- database availability and storage
- backup completion
- SSL expiration
- agent failures and excessive retry loops
- model and infrastructure usage

Use OpenTelemetry for instrumentation, Grafana for dashboards, Sentry for application errors, and Uptime Kuma for simple availability checks.
