# Genesis Reference Models

**Status:** Nonbinding examples and current-state mappings
**Version:** 0.1.0

Reference models illustrate how canonical contracts can be assembled. They do not create
provider support, tenant data, authority, or implementation status.

| Model | Purpose |
|---|---|
| [Genesis v0.1 platform](genesis-v0.1-platform.json) | Current, planned, proposed, and deferred platform posture |
| [Organization template](organization-template.json) | Reusable organization template separated from tenant operations |

Examples contain no secrets or real tenant records. Production instances must use stable
internal IDs, authorized configuration, schema validation, and provenance.
