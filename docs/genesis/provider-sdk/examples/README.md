# Provider SDK Examples

**Status:** Nonbinding examples

Examples illustrate the machine-readable contracts and must not contain usable
credentials, tenant data, or support claims.

- [Source-control provider](source-control-provider.json) demonstrates a candidate
  provider manifest with capability, configuration, authentication, health, lifecycle,
  events, timeouts, idempotency, observability, and conformance metadata.

Validate examples against the schemas in [`../../schemas/`](../../schemas/README.md).
