# Roadmap

## Phase 0 — Repository foundation

- Product vision and architecture
- Agent role definitions
- Workflow contracts
- Security and approval policy
- Issue and pull-request templates
- Baseline CI

## Phase 1 — Development workstation

- Ubuntu 24.04 bootstrap automation
- Browser IDE
- Docker and Git worktree support
- Claude Code and Codex installation adapters
- Local development services
- Secure secrets bootstrap

## Phase 2 — Deterministic workflows

- Archon integration
- Feature, bug-fix, CI-repair, documentation-sync and release workflows
- Agent task contracts and structured outputs
- Retry limits and escalation

## Phase 3 — Conversational orchestration

- OpenClaw integration
- Project and repository routing
- Approval inbox
- Agent activity and cost reporting
- GitHub issue and pull-request lifecycle automation

## Phase 4 — Quality and security factory

- Unit, integration and Playwright testing
- Testcontainers
- Gitleaks, Semgrep and Trivy
- Dependency automation
- Documentation execution tests

## Phase 5 — Delivery platform

- Coolify integration
- Preview environments
- Staging promotion
- Production approval gates
- Automated smoke tests and rollback plans

## Phase 6 — Observability and continuous improvement

- OpenTelemetry
- Sentry
- Grafana stack
- Workflow analytics
- Agent performance evaluation
- Post-incident and retrospective automation
