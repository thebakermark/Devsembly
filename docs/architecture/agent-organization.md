# Agent Organization

## Persistent lead agents

1. Chief Orchestrator
2. Product Director
3. Architecture Director
4. Engineering Director
5. Quality Director
6. Security Director
7. Platform Director
8. Documentation Director

## Temporary specialist agents

Spawn only when required:

- Business analyst
- Requirements analyst
- Solution, data, integration and infrastructure architects
- Backend, frontend, mobile, API and database engineers
- Unit, integration, browser, accessibility, performance and adversarial QA
- Application security, dependency, secret and threat-model reviewers
- CI, deployment, observability and incident specialists
- Technical writer and documentation verifier

## Separation of duties

- The implementing agent cannot be the final reviewer.
- The orchestrator cannot bypass required checks.
- Production deployment requires a separately authorized approval.
- Security findings classified as critical or must-fix block promotion.
