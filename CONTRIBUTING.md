# Contributing

1. Start from a GitHub issue with acceptance criteria.
2. Create a branch or isolated Git worktree.
3. Make the smallest coherent change.
4. Add or update tests.
5. Run repository validation and security checks.
6. Update documentation when behavior changes.
7. Open a draft pull request using the template.
8. Obtain independent review; an agent may not approve its own work.
9. Do not merge until required GitHub checks pass.
10. Production promotion requires its own approval.
